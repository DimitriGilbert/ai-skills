# Sources — Multi-Agent Orchestration Research (2025–2026)

Research date: 2026-09-01. Companion to REPORT.md.

## Primary / official sources

- https://code.claude.com/docs/en/sub-agents — Claude Code subagents docs. Taken: full frontmatter spec (name, description, tools, model, modelProvider, permissionMode, memory, maxTurns, skills, initialPrompt, background, disallowedTools, mcpServers, hooks, effort, isolation), official product-designer example agent (frontmatter + prompt body), reference to code-reviewer/debugger/doc-writer examples with Success criteria, description-as-trigger best practice, context isolation semantics, nested spawn depth (3) and concurrency (20) limits with env vars, background subagents + SendMessage to running agents + resume-by-agent-id, sibling roster injection, subagent-output injection scanning, role-based model configs JSON, `/model <agent-name>` live switching, memory dirs (MEMORY.md 200 lines/25KB).
- https://code.claude.com/docs/en/agent-teams — Claude Code agent teams docs. Taken: enable flags (CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS, CLAUDE_CODE_EXPERIMENTAL_MULTI_SESSION_TEAMS), TeamCreate/TaskCreate/TaskUpdate/TaskList/SendMessage primitives, shared task list with file locking + status/owner, JSON mailbox files for state consistency, TeammateIdle/TaskCreated/TaskCompleted hooks, full TeamSpawnPrompt spawn template, four deployment patterns (layered/pipelined/isolated/competing-hypotheses), teammate sizing 3-5, restriction types (task/file/command/mcp), teams dir `~/.claude/teams/<name>/`, "Explicit coordination is the best practice".
- https://www.anthropic.com/engineering/multi-agent-research-system — Anthropic engineering (Jun 2025). Taken: orchestrator-worker architecture, plan-to-memory (200k truncation), four-part task brief (objective/output format/tools/boundaries), semiconductor-shortage failure example, effort-scaling prompt rules (1 agent 3-10 calls; 2-4 agents 10-15 calls; 10+ for complex), 90% research-time cut from 3-5 parallel launches, traits-over-rules prompt philosophy, agents rewriting tool descriptions (40% task-time win), 90.2% eval improvement, 80% variance explained by tokens, 15x token multiplier, model-choice-as-multiplier quote, game-of-telephone/filesystem-artifacts rule, eval guidance (~20 queries, single LLM-judge, outcomes-not-paths, content-farm bias), durable execution + rainbow deployments.
- https://platform.claude.com/docs/en/build-with-claude/compaction — Compaction API docs (2026). Taken: beta header + config shape, trigger (default 150k, min 50k, per-iteration check), 4-step flow, default summarizer prompt excerpts, custom instructions replace-not-supplement with example, pause_after_compaction + keep-last-3-messages pattern, budget pattern ("Please wrap up..."), cache_control on system prompt, usage/iterations billing notes.
- https://platform.claude.com/cookbook/tool-use-context-engineering-context-engineering-tools — Anthropic context-engineering cookbook. Taken: benchmark numbers (6.7% → 60.4% notes → 77.2% +compaction → 79.1% +tool clearing; 3x/4x/8x token multipliers), full agent-memory/noteskeeping prompt, max-4-notes overwrite rule, compaction prompt with `<silent_history>`, structured note-taking definition.
- https://openai.github.io/openai-agents-python/multi_agent/ — OpenAI Agents SDK orchestration docs. Taken: agents-as-tools vs handoffs definitions and when-to-use table, mixing pattern, code-driven patterns (chaining, generator/evaluator loop, asyncio.gather parallelism, structured-output routing), single-purpose-agent guidance.
- https://openai.com/index/the-next-evolution-of-the-agents-sdk/ — OpenAI (Apr 2026). Taken: SandboxAgent code example, Manifest workspaces, snapshot/rehydration durability, credential isolation rationale.
- https://adk.dev/agents/multi-agents/ — Google ADK multi-agent docs. Taken: agents-as-tools vs manager (`transfer_to_agent`) contrast, workflow_agent, 4-step orchestrator loop, agent-tree scope rule, session-state blackboard quote (output_key/state_key/callbacks), SequentialAgent/ParallelAgent/LoopAgent with stateInvocationCheck, outliner/writer/reviewer examples.
- https://adk.dev/a2a/ (+ https://github.com/a2aproject/a2a) — A2A protocol. Taken: open cross-framework agent communication standard, Apr 2025 launch, Linux Foundation governance. Contextual only.
- https://docs.ag2.ai/latest/docs/user-guide/advanced-concepts/orchestration/group-chat/patterns/ — AG2/AutoGen. Taken: five group-chat patterns (Default/Auto/RoundRobin/Random/Manual) with next-speaker mechanisms and OnCondition/StringLLMCondition handoff code, nested chats as inner monologue.
- https://docs.crewai.com/v1.15.17/en/learn/hierarchical-process — CrewAI. Taken: manager_llm vs manager_agent code, allow_delegation default-off, manager task allocation + result validation workflow, planning=True.

## High-value secondary / practitioner sources

- https://cognition.com/blog/dont-build-multi-agents — Cognition (Jun 2025, Walden Yan). Taken: Principle 1 ("Share context, and share full agent traces, not just individual messages"), Principle 2 ("Actions carry implicit decisions, and conflicting decisions carry bad results"), single-threaded linear agent recommendation, context-compressor model proposal, Flappy Bird/Super Mario divergence example.
- https://cognition.com/blog/multi-agents-working — Cognition (Apr 2026). THE key modern source. Taken: generator-verifier loop with clean-context reviewer (2 bugs/PR, 58% severe-bug catch), smart-friend pattern (30+ point quality gain, escalation costs, SWE-1.5 self-awareness failure), cross-frontier capability routing, manager-child MCP spawning with failure modes (over-prescription, assumed shared state "Non-existent file", dropped cross-agent messages) and fixes (what-not-how, disk-over-messages), "map-reduce-and-manage", "writes stay single-threaded... agents contribute intelligence rather than actions".
- https://claudefa.st/blog/guide/agents/agent-teams-best-practices — Practitioner best practices. Taken: model-per-role criticality, broken-teammate recovery via SendMessage ("Check TaskList"), prompt-refinement loop, conflicting-priorities warning, handoff.md > /compact rationale and recommended handoff-doc contents (state/next steps/open questions/key files).
- https://alexop.dev/posts/from-tasks-to-swarms-agent-teams-in-claude-code/ — Technical deep dive. Taken: "task files on disk and SendMessage are the only coordination channels — there's no shared memory", no inherited conversation history, task description-as-prompt ("detail there drives agent quality"), JSON task fields (id/subject/description/status/owner), Opus lead + Sonnet teammates cost pattern, full team lifecycle (TeamCreate → ... → shutdown handshake → TeamDelete), plan-first-then-team recipe.
- https://oneaway.io/skills/agent-team — Community agent-team skill. Taken: spawn prompt structure (Role/File Ownership own+DO-NOT-TOUCH/Context/7-step loop/Rules), SendMessage types (message/shutdown_request/plan_approval_response), shutdown protocol with TeamDelete, max-4 teammates, one owner per file, read-only agent types for review only, "File conflicts are the #1 failure mode", idle-is-normal, no-broadcast rule, two-failure re-plan rule, team-vs-subagent gate (3+ independent streams).
- https://www.langchain.com/blog/how-and-when-to-build-multi-agent-systems — LangChain. Taken: synthesis of Anthropic vs Cognition positions, when multi-agent helps (breadth-first, context limits, high-value), coordination-limitation quote, read-vs-write asymmetry, context engineering as #1 job, durable execution, ~20-datapoint evals, buy-vs-build.
- https://www.langchain.com/blog/benchmarking-multi-agent-architectures — LangChain benchmark. Taken: modified τ-bench setup, single-agent collapse with 2+ distractor domains, swarm vs supervisor tradeoffs (translation/telephone cost, token curves flat vs growing), the three supervisor fixes (remove handoff messages, forward_message tool, delegate_to_/transfer_to_ naming) worth ~50% performance.
- https://getunblocked.com/blog/model-routing-coding-agents/ — Model routing for coding agents. Taken: routing vs cascading distinction, 30-40% savings vs rework-exceeds-savings caveat, 40-85% vendor claims as directional, cascade+verifier as the correct primitive, machine-checkability of coding, latency benefits of cheap models, 72.5%-accuracy/one-tenth-cost entity-picker agent.
- https://www.reddit.com/r/ClaudeAI/comments/1p6rksl/dont_compact_handoff_with_claude_code/ — Community. Taken: dump-to-markdown → /clear → re-seed handoff loop as the alternative to /compact.
- https://oneaway.io/skills/agent-team and https://claudefa.st/... (see above) also supplied the spawn/shutdown templates quoted in REPORT.md.
